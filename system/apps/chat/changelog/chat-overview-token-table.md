The Agent Overview's token figures move into their own table.

The activity table is back to four columns, and tokens now sit below it as a small table of their own: rows for Input and Output, columns for New, Cached and Total. The previous shape put one token figure in the activity table and the other three in prose beneath it, which split one subject across two presentations and left a column of dashes against every tool row.

Two things the grid states rather than hides. Cache writes count as New input -- the model read those tokens for the first time as well as storing them, so they are new traffic, not a saving. And Output has no cached figure at all, because generated tokens are never served from a cache.
